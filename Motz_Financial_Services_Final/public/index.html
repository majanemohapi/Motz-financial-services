About this system

Fundamentals of Artificial Intelligence. The classifier is implemented in Prolog. The source dataset is the Kaggle Loan Prediction Problem training dataset (614 labelled rows, 12 input features and Loan_Status target).

Important: This dataset is a public benchmark, not Motz Financial Services' own customer data. The model may reflect historical bias and must not be used as the sole basis for real lending decisions.
